Frontend application for KanbanLite — a modern task management platform.

Features:
- Create tasks
- Update tasks
- Delete tasks
- Mark completed/pending
- Responsive UI
- Toast notifications
- Animations

## Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Axios
- Framer Motion
- Lucide Icons
- React Hot Toast

## Environment Variables

Create `.env.local`:

NEXT_PUBLIC_API_URL=http://localhost:5000/api

NEXT_PUBLIC_API_URL=https://kanbanlite-backend.onrender.com/api

## Run Locally

Clone the repo:

git clone https://github.com/YOUR_USERNAME/KanbanLite-Frontend.git

Install dependencies:

npm install

Run app:

npm run dev
